SOCHACZEW ODPADY

1. Rozpakuj ZIP.
2. Otwórz folder w VS Code.
3. Zainstaluj Live Server.
4. Prawy klik na index.html -> Open with Live Server.
5. Zdjęcie miasta włóż jako: assets/sochaczew.jpg

Funkcje:
- wyszukiwanie ulic,
- najbliższy odbiór,
- kolejne terminy,
- kalendarz,
- ulubione z własną nazwą,
- zmiana nazwy i usuwanie,
- ustawienia,
- tryb ciemny,
- PWA.

Publikacja:
- GitHub Pages / Netlify / Cloudflare Pages.
- Po publikacji przez HTTPS aplikację można instalować na telefonie jako PWA.
- Później można zrobić APK/AAB i aplikację iPhone przez Capacitor.

Ulubione i ustawienia są zapisywane lokalnie w przeglądarce.
